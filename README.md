# Haulo-Homepage

HAULO Interactive 3D Website with WebGL, GSAP conveyor animations, and responsive space mech ring sequence.

## Tech Stack
- React 19 + Vite
- Three.js + WebGL
- GSAP + ScrollTrigger
- Draco 3D Compression

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
